# Core Mathematical Engine

The `neurogebra.core` module forms the foundational mathematical and computational backbone of NeuroGebra. It provides the unified `Expression` class with dual symbolic and numerical capabilities, `MathForge` expression registry, micro-autograd engine (`Value` and `Tensor`), `Trainer`, and `NeuroCraft` interactive exploration.
