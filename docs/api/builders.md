# Model Builder & Neural Network Architecture

The `neurogebra.builders` module provides an intuitive, high-level declarative interface for composing neural networks layer-by-layer, including classic layers (Dense, Conv2D, Dropout, Flatten, MaxPooling2D, BatchNorm) and modern architectures (LayerNorm, GlobalAveragePooling2D, ResidualDense).
