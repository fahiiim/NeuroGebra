# Start with something you can inspect

NeuroGebra 3.0 combines symbolic exploration, small neural models and training observability. You can begin with the core package; native compilers and GPU libraries are optional.

| Step | What you will do |
|---|---|
| [Install](installation.md) | Create an isolated environment and choose optional integrations |
| [Write your first program](first-program.md) | Evaluate a formula, differentiate it and train a small model |
| [Understand the architecture](how-it-works.md) | Distinguish symbolic evaluation, eager autograd, layer backpropagation and native kernels |
| [Check capabilities](../project/capabilities.md) | Choose suitable workloads and understand the current limits |

## Pick a learning path

- **New to scientific Python:** [Python basics](../python-refresher/basics.md), [NumPy](../python-refresher/numpy.md), [data handling](../python-refresher/data-handling.md).
- **Learning machine learning:** [ML fundamentals](../ml-fundamentals/what-is-ml.md), then the [beginner track](../tutorials/beginner.md).
- **Already building models:** [ModelBuilder](../tutorial/model-builder.md), [optimization](../advanced/optimization.md), [Observatory](../tutorial/training-observatory.md).
- **Upgrading from 2.x:** [Migration guide](../releases/migration-3.md) and [release notes](../releases/3.0.0.md).

The [quick reference](../getting-started.md) is available for returning users.
