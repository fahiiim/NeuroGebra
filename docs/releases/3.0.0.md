# NeuroGebra 3.0.0

**Release: 3.0.0 · Published November 2026.**

NeuroGebra 3.0 makes the library easier to explore and fixes important edge cases in training, checkpointing and scientific experiments. The documentation now presents one coherent guide from an executable formula to an inspectable model.

## Highlights & Interactive Web Experience

- **Interactive Documentation**: Interactive formula explorer, activation visualization, and loss progression demo right on the home page with full accessibility and keyboard navigation support.
- **Granular API Documentation**: Dedicated reference guides for `Expression`, `MathForge`, `Value`, `Tensor`, `Trainer`, and `NeuroCraft` with complete signatures, parameters, and executable examples.
- **Classic Documentation Design**: Warm paper tones, teal accents, serif headings, light/dark themes, responsive navigation, and local system fonts.
- **Full Reference Catalogs**: Generated catalogs covering all 285 formulas and 48 dataset loaders, with return conventions and provenance.
- **Frontend Quality Assurance**: Automated regression tests (`tests/web/home-demo.test.cjs`) validating graph bounds, ARIA states, and UI/Python agreement.
- **Updated Guides**: Architecture guide, first program, capability matrix, troubleshooting, contributor guide, migration notes and technical review.

## Runtime & Engine Fixes

- **Optimizer State Persistence**: Preserve built-in Adam, SGD, and RMSprop configuration, step counters, and momentum/velocity buffers in model checkpoints.
- **Numerically Stable Softmax / Cross-Entropy**: Compute Dense softmax cross-entropy loss directly from logits, with exact fused gradients for class indices and probability targets.
- **Categorical Target Validation**: Validate integer categorical labels and probability distributions; preserve true general softmax vector-Jacobian product.
- **PINN Residual Derivatives**: Differentiate every residual weight and bias (supporting matrices with >256 entries), normalize multi-output gradients across all elements, and safely restore parameters upon callback exceptions.
- **Analytical Derivative Caching**: Cache and reuse analytical derivative expressions and compiled numerical functions across training epochs.
- **Portable Native Acceleration**: Safe C compiler target detection, compiler-aware cache hashing, and configurable cache root via `NEUROGEBRA_CACHE_DIR`.
- **Checkpointing Hygiene**: Respect `metrics=[]` and explicitly reject unsupported custom optimizer checkpoint serialization.

## Upgrade notes

The [migration guide](migration-3.md) explains numerical behavior changes, old checkpoints and native backend compatibility. The core package still requires Python 3.9+. No claim of universal performance superiority over other ML frameworks is made in this release.

## Known boundaries

Neural models and PINNs train with NumPy. PINN residual differentiation is numerical and can be expensive. The CUDA path evaluates supported expressions and transfers host arrays per call. Framework bridge capabilities differ. Pickle checkpoints require trusted inputs, and scheduler/RNG state is not saved. See [capabilities](../project/capabilities.md) and the [review and roadmap](../project/review-3.md).
