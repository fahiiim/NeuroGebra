    Framework Bridges & Built-in Datasets¶

    The neurogebra.bridges and neurogebra.datasets modules provide interoperability with PyTorch, TensorFlow, and JAX, as well as 48 zero-external-download dataset loaders for machine learning and scientific validation.

    Framework Bridges¶

    PyTorch Bridge¶

    PyTorch bridge for Neurogebra expressions.

    Datasets¶

    Standard Loaders (21 Datasets)¶

    neurogebra.datasets.loaders.Datasets ¶

    Pre-loaded datasets for learning.

    Provides easy access to common datasets with educational metadata.

    Examples:

    >>> from neurogebra.datasets import Datasets
>>> (X_train, y_train), (X_test, y_test) = Datasets.load_iris()
>>> X, y = Datasets.load_simple_regression()
