# Security Policy

## Supported Versions

Security updates and critical bug fixes are provided for the following versions:

| Version | Supported |
| ------- | --------- |
| 2.8.x   | Yes       |
| 2.7.x   | Yes       |
| 2.6.x   | Yes       |
| < 2.6   | No        |

## Reporting a Vulnerability

The NeuroGebra team takes the security of our software seriously. If you believe you have found a security vulnerability in NeuroGebra, please report it privately:

1. **GitHub Security Advisory**: Open a private draft security advisory via [GitHub Security Advisories](https://github.com/fahiiim/NeuroGebra/security/advisories/new).
2. **Email**: If you prefer email, contact the maintainer directly at `fahimsarker.dev@gmail.com` with the subject line `[SECURITY] NeuroGebra Vulnerability Report`.

### What to Include
- A description of the vulnerability and its potential impact.
- Clear steps or a minimal script to reproduce the issue.
- Any suggested mitigations or patches if available.

### What to Expect
- **Initial Response**: Within 48 hours, we will acknowledge receipt of your report.
- **Assessment**: We will evaluate the report and coordinate an assessment within 5 business days.
- **Resolution**: Once verified, we will develop a patch and coordinate a security advisory release on GitHub and PyPI.
